# Opportunity Facts

Opportunity Facts turns public pages about student opportunities into standardized, source-backed facts cards. Students and families can inspect evidence, compare two or three opportunities, build a card manually, and export their work without creating an account.

The product reports what reviewed sources disclose. It does **not** rate legitimacy, quality, prestige, admissions impact, or value, and it does not independently audit an organizer's claims. `not_found`, `unclear`, and `conflicting` are intentional results.

The bundled dataset contains seven clearly labeled fictional `.example` demo cards and three independently researched, human-reviewed real cards for the current NASA TechRise, Lumiere Research Scholar, and Diamond Challenge cycles. Human review verifies source alignment; it is not an organizer endorsement or independent legitimacy audit.

All repository cards use schema `2.0.0`. The 59-field facts map remains the stable summary/comparison surface, while evidence-bearing structured records preserve cycle identity, multiple organizations, tiered prices, stage/pathway differences, and outcome scope without flattening them into misleading scalars. The disclosure meter leads with assessed core areas, then reports applicable disclosures and the remaining evidence states; it is assessment coverage, not a score. The repair is documented in [`REALITY_STRESS_TEST_RESOLUTION.md`](REALITY_STRESS_TEST_RESOLUTION.md).

## Architecture

Opportunity Facts is a Next.js App Router application with strict TypeScript, React, Tailwind CSS, Zod, Vitest, and Playwright. It does not require a database.

- `lib/opportunity/schema.ts` exports the authoritative schema `2.0.0` contract. `schema-v2.ts`, `structured-schema.ts`, `projection.ts`, and `migration.ts` enforce structured evidence, deterministic 59-field projections, and conservative V1 import; `registry.ts` retains exactly 13 core assessment areas.
- Repository JSON powers public demo and reviewed cards. Browser storage holds only user-requested drafts and comparison selections.
- Server-side URL acquisition validates DNS and every redirect, connects to the validated address, limits content type/time/bytes, and discovers at most six relevant same-origin pages.
- HTML is reduced to normalized, non-executable text. Source-page instructions are treated as hostile data.
- Optional model extraction uses the official OpenAI JavaScript SDK and Responses API with provider-compatible strict Zod structured output, a 120-second timeout, low reasoning effort, no automatic retries, and a shared input budget distributed across all acquired pages. Deterministic post-processing rejects unsupported excerpts, typed-value mismatches, unsafe relationship/scope upgrades, and incomplete prize flattening.
- API analysis responses are transient and marked `Cache-Control: no-store`. The application has no analytics or hidden telemetry.

See [`PROJECT_SPEC.md`](PROJECT_SPEC.md), [`docs/SCHEMA_AND_DATA.md`](docs/SCHEMA_AND_DATA.md), and [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md) for the durable contract and security boundaries.

## Install and run

Prerequisites: Node.js 20.9 or newer and npm.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Open `http://localhost:3000`. An OpenAI key is optional; samples, browsing, comparison, manual building, imports, exports, research, and methodology all work without it.

For a production-mode local run:

```powershell
npm run build
npm run start
```

## Adding a reviewed card

1. Run `npm run create:card -- <lowercase-kebab-case-slug>`.
2. Edit the new file in `data/drafts/` using only public sources and keep `reviewState: "draft"` while review is incomplete.
3. Inventory the opportunity/cycle separately, assess every structured collection, and attach evidence to each independently reviewable organization, role/scope, timing, cost, pathway, and outcome assertion. The builder generates mapped flat facts; do not edit V2 projections directly.
4. Attach an exact source excerpt to every displayed factual value. Preserve supported disagreements as conflicts; do not choose a preferred value or flatten tier/pathway differences.
5. Use `human_reviewed` only after checking value, excerpt, source, scope, projection, and structured-record alignment. `organizer_confirmed` means supplied or confirmed by the organizer, not independently audited.
6. Complete [`docs/REVIEW_CHECKLIST.md`](docs/REVIEW_CHECKLIST.md), set a truthful reviewed state and timestamp, then move the file to `data/opportunities/`.
7. Run `npm run export:data`, `npm run validate:data`, and `npm test`. The exporter fails closed on drafts, stale projections, duplicate opportunity/cycle identities, or unassessed reviewed structures.

Schema V1 files may still be imported for recovery, but they always become draft V2 revisions. The migration preserves legacy facts and evidence, records a digest, clears review attestation, and requires manual structured review before publication.

The aggregate dataset is available at `/api/dataset` and `public/data/opportunities.json`; the machine-readable schema is available at `/api/schema` and `public/schema/opportunity-card.schema.json`.

## Analysis boundaries

- Only unauthenticated public HTTP(S) pages are accepted. Local, private, link-local, metadata/platform-service, credential-bearing, sensitive-query/fragment, and unsafe redirect destinations are rejected.
- A request has a 10-second fetch deadline, a 1.5 MB response limit, at most five redirects, and at most six discovered same-origin pages. Only HTML and plain text are accepted.
- Static extraction cannot reproduce every client-rendered site, shadow DOM, computed visibility rule, or anti-bot flow. Paste-source mode is the fallback.
- Automated URL and paste analysis labels sources `user_supplied`; paths, branding, and same-origin discovery do not prove that a page is official.
- Model extraction can omit or misunderstand disclosures. Exact excerpt matching proves text presence, not truth, authority, or correct interpretation; drafts still require human review.
- Per-request controls do not replace deployment-level rate limits, concurrency limits, spend alerts, or outbound-network policy.

## Privacy behavior

Submitted URLs and pasted text are processed transiently and are not written to an application database. If model extraction is configured, normalized public source text is sent to OpenAI with `store: false`; provider and hosting logs remain governed by their respective account settings and policies. Remote sites and DNS resolvers observe fetches. Drafts and comparison selections persist locally only when the user asks to save or compare, and downloads persist wherever the browser or device stores them.

## Deploying to Vercel

Import the repository as a Next.js project, keep the default build command (`npm run build`), and add only the environment variables needed for the deployment. Store `OPENAI_API_KEY` as a server-side secret and do not expose it to preview builds for untrusted changes. After deployment, verify response security headers, the no-key and configured analysis paths, outbound-network controls, request/concurrency limits, log retention, and model spend limits.

No deployment is performed automatically by this repository.

The research page intentionally says **Study not yet published** until real results exist. No users, metrics, organizer responses, or accuracy claims are fabricated.

The first live-provider extraction development benchmark is preserved locally in
[`EXTRACTION_BENCHMARK.md`](./EXTRACTION_BENCHMARK.md). It uses the three existing
human-reviewed cards as a tuning set and is explicitly not independent or
out-of-sample accuracy evidence.

The subsequent [`OUT_OF_SAMPLE_EVALUATION.md`](./OUT_OF_SAMPLE_EVALUATION.md)
preserves one frozen production run on each of seven preregistered opportunities.
The public library now contains all ten independently assembled human-reviewed
cards plus seven clearly fictional demos. The evaluation found four critical
misleading automated claims, so automated output remains a draft requiring human
source review; it is not suitable for unattended publication.
